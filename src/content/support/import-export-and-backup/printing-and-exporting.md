Helium can print (or export to PDF) from any screen, as well as formatted notes, and the **Todos** view can be exported to a CSV file.

## Printing

The **Planner**, **Notebook**, **Classes**, **Resources**, **Grades** screens can be printed using the standard keyboard shortcuts:

  * **Mac:** Cmd + P
  * **Windows / Linux:** Ctrl + P

Helium generates a PDF preview, which can then be sent to a printer or saved to disk.

### Printing a Note

To print a formatted note:

  1. Open [**Notebook**](https://app.heliumedu.com/notebook) and tap the note
  2. Tap the print icon in the editor toolbar

Printing a single note is available on iOS, Android, and the web.

## Exporting Todos to CSV

  1. Open the [**Planner**](https://app.heliumedu.com/planner) and switch to the **Todos** view
  2. Apply any filters or sort order you want reflected in the export
  3. Tap **Export CSV** in the footer

The exported file includes a row for every todo that matches your current filters, with columns for:

  * **Completed** — Yes or No
  * **Title**
  * **Due** — date, or date and time if not all-day
  * **Class**
  * **Category**
  * **Priority**
  * **Grade** — populated for completed assignments
  * **Resources** — included only if any exported todo has linked resources
