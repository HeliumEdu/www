Each class in Helium can have one or more **schedules**. A schedule is a meeting pattern — the days and times a class meets — and Helium uses it to generate recurring **Class Schedule** items on your Planner for every occurrence within the class's date range.

Most classes need just one simple weekly schedule. But a class can also have several schedules at once (a lecture plus a separate lab), follow a rotating pattern (A/B days or a fixed-length cycle), or have a schedule that runs for only part of the term.

## Opening the Schedule tab

All schedules are managed from the **Schedule** tab of a class.

  1. Open [**Classes**](https://app.heliumedu.com/classes) and click a class (or add a new one)
  2. Go to the **Schedule** tab
  3. Under **Schedules**, click the **+** (**Add schedule**) button to create a schedule, or click an existing schedule to edit it

Each schedule appears as its own card showing its days and times. To remove a schedule, use the delete icon on its card.

A schedule is optional — if a class has no fixed meeting time (e.g., a fully asynchronous online class), you can leave the Schedule tab with no schedules.

## Weekly schedules

A weekly schedule meets on the same days every week — the most common setup.

  1. In the schedule editor, make sure **Weekly** is selected at the top
  2. Under **Class Days**, click each day the class meets to include it
  3. Set the **Class Time** — the **Start** and **End** times
  4. If the class meets at _different_ times on different days (e.g., a Friday lab runs longer), check **Varies by day** to set independent start and end times for each selected day
  5. Click **Save**

## Multiple schedules per class

Some classes meet in more than one pattern — for example, a lecture on Monday/Wednesday/Friday and a lab on Tuesday afternoon. Rather than forcing both into a single schedule, add a separate schedule for each:

  1. Set up the first schedule (e.g., the lecture) and click **Save**
  2. Back on the **Schedule** tab, click **+** (**Add schedule**) again
  3. Set up the second schedule (e.g., the lab) and click **Save**

Each schedule is edited and deleted independently, and each generates its own Class Schedule items on the Planner.

## Rotating schedules

Many schools run rotating schedules — A/B days, a fixed-length day cycle, or alternating weeks — where the meeting pattern doesn't line up with an ordinary calendar week. To set one up, choose **Rotating** at the top of the schedule editor, then pick a pattern from the **Rotation** dropdown.

### Day cycles

A day cycle rotates through a fixed number of "cycle days" — Day 1, Day 2, and so on — advancing one cycle day per school day, independent of the calendar week.

  1. Select **A/B Day**, **6-Day Cycle**, **7-Day Cycle**, **8-Day Cycle**, or **10-Day Cycle** from the **Rotation** dropdown
  2. For each cycle day (**Day 1**, **Day 2**, …), toggle whether the class meets and set its **Start** and **End** times
  3. Set **Cycle Day 1 falls on** to the calendar date your cycle's Day 1 lands on, so Helium can line the rotation up with your calendar
  4. Click **Save**

If your school uses a cycle length Helium doesn't offer, [let us know](/support/submit/) and we'll look at adding it.

### Week rotations (Week A/B)

A week rotation has the class meet **every other week**, alternating by calendar week. You may also know this as **odd/even weeks**, **single/double weeks**, or **fortnightly**. For example, a class that meets only on "A" weeks.

  1. Select **Week A/B** from the **Rotation** dropdown
  2. Choose the weekly pattern under **Class Days** and **Class Time**, the same way as a weekly schedule
  3. Under **Which week**, pick the week in the rotation this schedule meets on (**Week A**, **Week B**, …)
  4. Set **Week A begins on** to the date the first week of the rotation starts, so Helium knows which calendar week is which
  5. Click **Save**

**Which week is "A"?** Helium counts forward from the **Week A begins on** date — that week is A, the next is B, and so on. Set it to the first day of the earliest week your rotation is "on," reading from your school's timetable or calendar. If the Planner shows the pattern flipped after you save, shift the anchor one week.

If your "A" and "B" weeks have _different_ day patterns, add a separate schedule for each — one for Week A and one for Week B (see **Multiple schedules per class** above).

## Limiting a schedule to part of the term

By default a schedule runs for the class's whole date range. To limit one schedule to a shorter window — for example, a lab that only meets during the first six weeks — give that schedule its own dates:

  1. In the schedule editor, find **Class Dates**
  2. Turn on **Custom range**
  3. Set the **From** and **To** dates for this schedule

Only this schedule is affected; the rest of the class keeps its normal date range. This is useful for labs, review sessions, or any block that runs for only part of the term.

**Class dates vs. schedule dates:** to make an _entire class_ start late or end early, set the class's own **From / To** on the **Details** tab instead. Use **Custom range** here only when one schedule needs a shorter window while the rest of the class keeps meeting.

You can combine a custom range with a rotation — for example, a lab that meets only on "B" weeks _and_ only during the first eight weeks of term: set up the Week A/B rotation, then turn on **Custom range** and set the window to those eight weeks.

## Where schedules appear

Class Schedule items appear on the **Week**, **Day**, **Month**, and **Agenda** views of the Planner. They do _not_ appear in the **Todos** view, which shows assignments only. If a schedule isn't showing up, see [Why Items Aren't Showing on the Planner](/support/calendar-and-schedule/why-items-arent-showing-on-the-planner/).

To skip individual sessions or block out term-wide holidays, see [Cancelling Class Sessions and Setting Term Holidays](/support/classes/cancelling-class-sessions-and-setting-term-holidays/).
